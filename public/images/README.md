# DWPS — images folder

Every file here is a **named placeholder** at the correct aspect ratio.
To use a real photo, replace the file with your own image **using the exact same filename**.
The website loads each image from this folder by name — no code changes needed.

- Recommended: export as optimised **JPG** (or WebP). Match the ratio; the site crops with `object-fit: cover`.
- For Next.js: move this folder to `/public/images` and set `IMG = "/images/"` in the code.
